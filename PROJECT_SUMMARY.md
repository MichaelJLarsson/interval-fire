# Fire Interval - Interval workout timing app

## Project summary

An interval timing app that's easy and fun to use. It logs your workout history and provides some basic stats to better track your progress. Interaction should be very intuituve and easy so that it doesn't take focus away from the workout. It might be difficult to handle the phone during a run or a workout bout. Buttons and interactive elements should be easy to reach and large enough to aid interaction. The timing screen is very minimal with only the most critical information visible.

## Philosophy

There is no onboardingi and the app doesn't require you to sign up, but a sign-in feature might be added for the user to store their data and access it over time.

There are no menus in this app. All interactivity and settings are intuitively integrated in the UI. You shouldn't have to look around in menus for a specific setting, but it should be available just in time when you need it.
